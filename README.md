# English

## Overview

UI Style Extraction Skill is an AI-powered design analysis skill that extracts the visual design language of a website and converts it into structured, AI-friendly prompts.

Unlike website cloning tools, this skill does **not** reproduce layouts, business logic, content, or functionality.

Its purpose is to identify and extract the underlying **Design DNA** of a website, allowing AI to generate entirely new interfaces with the same visual style and design philosophy.

# 中文

## 项目简介

UI Style Extraction Skill 是一个专门用于分析网站视觉风格的 AI Skill。

它能够将网站的设计语言提取出来，并转换为 AI 可理解的结构化提示词（Prompt）。

与传统的网站复刻工具不同，本项目**不会分析页面布局、功能逻辑或业务流程**。

它专注于提取网站背后的：

* 设计语言（Design Language）
* 设计系统（Design System）
* 品牌气质（Brand Personality）
* 视觉风格（Visual Style）

从而帮助 AI 在完全不同的产品中复现相同的视觉风格。

## 核心理念

传统网站复刻：

```text
网站 → 相似网站
```

UI Style Extraction：

```text
网站 → Design DNA → 任意产品
```

目标不是复制网站。

而是提取设计基因。

让 AI 学会设计风格，而不是记住页面结构。
